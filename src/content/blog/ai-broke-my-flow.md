Before AI, I could code for hours in pure flow. Now I type a prompt, wait, get 300 lines back, and spend the next 20 minutes reviewing code I did not write.

That is not building. That is supervising.

## What broke it

1. **Big batches.** One prompt, a wall of code.
2. **Dead time.** While the agent works, I reach for my phone.
3. **Lost mental model.** Code I did not write does not stick.
4. **Interruptions.** Permission prompts pull me out every few minutes.

## What I am changing

Short loops. Smaller changes per turn. More conversation, less code dumping. And voice, so the gap between thinking and asking gets close to zero.
